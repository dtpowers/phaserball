# Beat-Synced Audio & Visuals — Design Spec
**Date:** 2026-06-08  
**Status:** Approved

## Overview

Add a persistent 110 BPM kick drum, beat-synced bumper glow, and hi-hat on bumper hit to reinforce the rave/electronic music theme of the Earkandi Pinball game.

## BPM Constants

Defined at the top of `src/scenes/MusicScene.js`:

```js
const BPM = 110;
const BEAT_MS = 60000 / BPM; // ~545.45ms
```

`BEAT_MS` is the single source of truth for all beat-synced timing. Changing `BPM` automatically adjusts the kick loop interval, glow fade duration, and anything else derived from it.

## MusicScene (`src/scenes/MusicScene.js`)

A new lightweight Phaser scene that runs persistently in parallel with all other scenes.

- Added to the scene list in `src/main.js`
- Launched from `BootScene.create()` via `this.scene.launch('MusicScene')` before `this.scene.start('GameScene')`
- Never stopped — persists across GameScene restarts and GameOverScene overlays

**`create()` behavior:**
- Starts a looping `this.time.addEvent({ delay: BEAT_MS, loop: true, callback: onBeat })`

**`onBeat()` behavior:**
1. `this.sound.play('kick')` — plays the kick drum sample
2. `this.game.events.emit('beat', { interval: BEAT_MS })` — broadcasts beat timing to all scenes

## Audio Assets

All files live in `public/assets/sfx/`. Custom samples can be dropped in by replacing the files — no code changes needed.

| Key | File | Description |
|-----|------|-------------|
| `kick` | `public/assets/sfx/kick.wav` | Kick drum — placeholder generated by `gen-sfx.js` (sine sweep ~150ms) |
| `hihat` | `public/assets/sfx/hihat.wav` | Hi-hat — placeholder generated by `gen-sfx.js` (noise burst ~80ms) |

`scripts/gen-sfx.js` gets two new `writeWav()` calls to generate these placeholders.

`BootScene.preload()` loads both under their respective keys.

## Bumper Glow (GameScene changes)

### Storage
`buildBumpers()` pushes each glow circle (`this.add.circle(...)`) into a new `this._bumperGlows` array instead of discarding the reference. The existing idle ambient tween (`1500ms yoyo repeat`) is removed entirely.

### Beat subscription
In `create()`:
```js
this.game.events.on('beat', this._onBeat, this);
```

In `shutdown()`:
```js
this.game.events.off('beat', this._onBeat, this);
```

### `_onBeat({ interval })`
Triggers on every kick beat. Tweens all glow circles simultaneously:
```js
this.tweens.add({
  targets: this._bumperGlows,
  alpha: { from: 0.35, to: 0 },
  duration: interval,
  ease: 'Sine.easeIn'
});
```
The glow flashes to 0.35 opacity on the kick and fades to 0 just before the next beat.

## Bumper Hit Sound (GameScene changes)

In `setupCollisions()`, replace:
```js
this.sound.play('bumper-hit');
```
with:
```js
this.sound.play('hihat');
```

The `bumper-hit` asset remains loaded in BootScene (no harm, avoids breaking anything that might reference it).

## Files Changed

| File | Change |
|------|--------|
| `src/scenes/MusicScene.js` | **New** — persistent beat scene |
| `src/main.js` | Add MusicScene to scene list |
| `src/scenes/BootScene.js` | Load `kick` + `hihat`; launch MusicScene |
| `src/scenes/GameScene.js` | Store glow refs, remove ambient tween, subscribe to beat, replace bumper-hit with hihat |
| `scripts/gen-sfx.js` | Generate `kick.wav` and `hihat.wav` |

## Out of Scope

- Tempo changes during gameplay
- Beat-syncing flipper or ball effects
- Stopping/muting music (no pause/mute controls in this game)
- Replacing the existing `ball-drain.wav` or `flipper-activate.wav`
